# 💼 CareerConnect - Job Portal Website

## 📌 Overview

CareerConnect is a modern and user-friendly job portal web application designed to simplify the job search process. It enables users to explore different job categories, apply for jobs, save opportunities, manage their profiles, and track their application progress through an interactive dashboard.

This project is developed using pure HTML, CSS, and JavaScript with browser LocalStorage for data management.

## 🚀 Features

### 👤 User Authentication
- User login and registration system
- Session handling using LocalStorage
- Secure logout functionality

### 🏠 Dashboard
- Personalized welcome message
- Job application statistics
- Saved jobs counter
- Profile completion tracker
- Application analytics charts

### 🔎 Job Search & Categories
- Search jobs based on keywords
- Browse different job categories:
  - 💻 Software Jobs
  - 🎓 Internships
  - 🏠 Work From Home Jobs
  - 🏛 Government Jobs
  - ⏰ Part-Time Jobs

### 📄 Job Applications
- Apply for available jobs
- Track application status
- View application history
- Remove applications

### 🔖 Saved Jobs
- Save favorite job opportunities
- View saved jobs list
- Remove saved jobs
- Apply directly from saved jobs

### 👨‍💼 User Profile
- Manage personal information
- Profile completion progress
- Resume and profile image support

### 📊 Analytics
- Application growth chart
- Application status visualization using Chart.js

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/BATTULALavanya2005/CareerConnect-Job-Portal.git
```

### Navigate to the project folder

```bash
cd CareerConnect-Job-Portal
```

### Open the project

Open `index.html` in your browser or use VS Code Live Server.
